## Picking the right version

- **On dark backgrounds:** use the primary versions (light bars, gold cursor) or `*-transparent-for-dark`.
- **On light backgrounds:** use the onyx versions or `*-transparent-for-light`. Gold never goes directly on white.
- **On gold:** use the onyx versions (`*-on-gold`).
- **One colour only (embroidery, engraving, single-colour print):** use the gold-only, white-only or onyx versions.
- Don't stretch, rotate, recolour, outline or rearrange the logo. Keep clear space equal to the cursor's tail height around it.
